# DSA01 – Assignment 1 CO1: C++ Programs

This package contains one illustrative C++ source file for each of the 12 tasks.

## Compile
From a task folder, run:
```bash
g++ -std=c++17 -Wall -Wextra TaskXX.cpp -o TaskXX
```
On Windows, run `TaskXX.exe` after compilation.

## Important
- Verify every program on your own compiler before submitting.
- Capture genuine screenshots of your own compilation and execution.
- Some tasks are primarily analytical; their source files are demonstrations to support the written answer.
- Task 10 uses an illustrative fixed fare to compare scale; replace it with your actual journey dataset if your faculty expects measured totals.
- Task 12 uses a simplified month identifier for demonstration; a production pass should validate a complete date range.
